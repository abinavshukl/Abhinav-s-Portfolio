# Abhinav Kumar's Personal Portfolio

Welcome to the repository for my personal portfolio website! This project serves as a digital resume and a showcase of my web development journey, technical skills, and featured projects. 

You can view the live portfolio here: [https://abinavshukl.github.io/Abhinav-s-Portfolio/](https://abinavshukl.github.io/Abhinav-s-Portfolio/) (assuming standard GitHub Pages URL format)

## 🚀 Technologies Used
- **HTML5 & CSS3** for structure and styling.
- **Tailwind CSS** (via CDN) for utility-first responsive design.
- **Vanilla JavaScript** for dynamic interactions and responsive navigation.
- **Font Awesome** for scalable vector icons.
- **Google Fonts** (Inter) for clean and modern typography.

## 📂 Project Structure
- `index.html`: The main page containing all sections (Home, About, Skills, Experience, Projects, Contact).
- `style.css`: Custom CSS for animations, custom utilities, and scrollbar styling not covered by Tailwind.
- `script.js`: Handles interactions such as the mobile menu toggle, smooth scrolling, and scroll-spy for active navigation links.
- `my_images/`: Contains profile images and icons used on the site.
- `documents/`: Stores the downloadable CV/Resume PDF.
- `.agents/rules/`: Contains AI agent rules for maintaining the repository.

## 📌 Project Addition & Ordering Guide
When maintaining or contributing to the **Featured Projects** section in `index.html`, please adhere strictly to the following ordering logic:

1. **Live Projects First**: Any project that has a live demo link and the green "Live" badge must appear before any offline or non-live projects.
2. **Chronological Order (Latest First)**: Within the "Live" category and the "Not Live" category, order the projects from most recently added/created down to the oldest.

## 🛠️ How to Run Locally
1. Clone the repository: `git clone https://github.com/abinavshukl/Abhinav-s-Portfolio.git`
2. Navigate into the directory: `cd Abhinav-s-Portfolio`
3. Simply open `index.html` in your favorite web browser or use a local server like VS Code's Live Server extension.
